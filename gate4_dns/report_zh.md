## 1. Gate 4：DNS 求解器和正对照

### 1.0 求解器（按你的做法）

- **区域和展开：** y 方向关于 y = 1 镜像，周期延拓到 4。三个方向都用 Fourier，x 方向用实 FFT。网格：
  - x_j = j Lx/Nx；
  - y_j = −1 + 4j/Ny，所以 y = ±1 正好落在格点上；
  - z_j = j Lz/Nz。
- **数值方法：**
  - pseudo-spectral，旋转形式 u × ω；
  - 2/3 去混叠，每个方向保留 |m| ≤ ⌈N/3⌉ − 1；
  - 在 Fourier 空间用 Leray 投影 P = I − kkᵀ/|k|²；
  - Lawson RK4，粘性项用积分因子 exp(−νk²h)；
  - 批量维度同时推进，可达几百个算例。
- **扰动形式：** 演化 u′ = u − U。
  - v1 写成 du′/dt = P[(U+u′) × (ω_U+ω′)] + ν∇²u′。
  - v2 改成代数上等价的拆分形式 P[U × ω′ + u′ × (ω_U+ω′)]，原因见 1.1。
- **对称性：**
  - 数值核对后，九个模态共有的离散对称性恰好是 y 镜像、shift-reflect、shift-rotate，以及它们的组合。
  - 这三个生成元可交换，各自是对合，所以每一步在 Fourier 空间对它们逐个求平均，就是精确投影到对称子空间。
  - 对称算子的 Fourier 实现与格点上的精确置换对比，差 1e-14。
- **核对：**
  - 九个模态在网格上的取值与 Gate 1 的 sympy 转写相差 4e-16。
  - Gram 矩阵与单位阵相差 9e-16，‖U‖ = 1，所以 E = ‖u − U‖² 在九模子空间里等于 Σ(a_i − a_i^lam)²。
- **单步耗时（RTX A6000，float64）：**

  | 分辨率 | 每个算例每步 |
  |---|---|
  | 48×24×24 | 0.44 ms |
  | 64×32×32 | 1.0 ms |
  | 96×48×48 | 4.2 ms |

### 3.1 他们的设置和幅值定义（原文式 3）

- **两个幅值的定义：**
  - A_U = (max_{y,z} ΔU − min_{y,z} ΔU)/(2U_ref)；
  - A_W = (max_{x,y,z} W − min_{x,y,z} W)/(2U_ref)。
  - 两者都是"半峰峰值"速度，取的是初始时刻（加入 sinuous 扰动的那一刻）。A_W 是速度幅值，不是能量。
- **Couette：** Re = U_w h/ν = 500，盒子 2.5π × π，U_ref = 2U_w。
  - streak 由线性最优流向涡演化而来，取能量峰值的时刻。
  - sinuous 扰动是 Schoppa–Hussain 的固定形状 C{0, 0, (1−y²) sin αx}。
- **Blasius：** Re_δ* = 700，盒子 9δ* × 5.737δ*，U_ref = U_e。

### 3.2 三件事

1. **A_U 较大的一支：ln A_W,crit 对 A_U 是否近似线性？是。**
   - Couette，A_U = 8.7–27.9%：斜率 −0.125 ± 0.006（每个百分点），R² = 0.992。
   - Blasius，A_U = 6.8–25.6%：斜率 −0.0653 ± 0.0009，R² = 0.9985。
   - 只在 A_U ≳ 27% 处最后 1–2 个点弯折：Couette 变平，Blasius 变陡。这接近原文说的 streak 线性失稳幅值（约 25%）。
   - 两种流动的斜率差约 1.9 倍。
2. **A_U → 0 时 A_W,crit 是否趋于常数？数据没有覆盖到小 A_U，也看不到平台。**
   - 最小 A_U 的点：Couette 4.35%（对应 A_W = 9.6%），Blasius 2.28%（A_W = 8.0%）。
   - 这些点仍落在同一条直线上。
   - 外推到 A_U = 0 得到 17% 和 9.2%，但这只是外推，不是数据。原文也没有给出极限值。
3. **两支的交接位置：看不到平的一支，所以没有交接点。**
   - 原文说的 "cross-over"（A_W = A_U）在约 7.0%（Couette）和 6.2%（Blasius），曲线在那里并没有拐折。

### 3.3 与"对应关系（待核）"的比较

- **"A_U 相当于我们的 S"：**
  - A_U 是 streak 的半峰峰值，除以 U_ref，不是 ‖u_streak‖/‖U‖。
  - 对 Couette，审查代理推出的换算是 ‖u_streak‖/‖U_C‖ ≈ 1.65 A_U。这是推导结果，原文没有给。
  - 另外，A_U 是初始时刻的值，之后 streak 自由演化（原文："not frozen"）。
  - 所以 A_U 只能说是一个 streak 幅值，不是我们在 t* 处或对 t 取最大值的 S。
- **"(2) 对应波自己造涡（S 里的 y–y 项）"：原文的 DNS 解释不支持。**
  - 原文对小 A_U 区的解释（式 5）是"波的涡量被基本剪切线性地倾斜"，不是 y–y 二次项。
  - 只有原文的四变量玩具模型里有 σ_v w² 这种二次项，与你的说法一致。
  - 而且数据里根本没有出现 A_U → 0 的平台（见 3.2 第 2 点）。
- **"(1) 对应种子 × 增益"：** 数据确实呈 ln A_W 对 A_U 线性，这与"阈值 ≈ 种子 × exp(增益·A_U)"的形式相容。但原文没有这样表述，也没有给出 ln-线性的规律。

## 4. 与"待核"内容的核对汇总

| 待核内容 | 结果 |
|---|---|
| shift-reflect (u,v,w)(x,y,z) → (u,v,−w)(x+Lx/2, y, −z) 是九个模态共有的对称性 | **对**（数值：九个模态都不变，误差 < 1e-15） |
| shift-rotate (u,v,w)(x,y,z) → (−u,−v,w)(−x, −y, z+Lz/2) 是共有对称性 | **对** |
