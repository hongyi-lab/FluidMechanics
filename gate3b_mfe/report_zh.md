## 0. 结论摘要

1. **判据（预设）：** 测试中位数 ≤ 0.04 的最小 k 是 **k = 1**，M1 为 0.0394，95% CI [0.0363, 0.0427]。按判据记录 k = 1。但有三点要一起看：
   - **这是擦线通过。**
     - CI 跨过 0.04。
     - 另外 3 个收敛到同一类解的 M1 随机重启，测试中位数是 0.0414–0.0416，都略高于 0.04。
     - 若按 CI 上界判，或换一个重启，结论会变成 k = 2。M2 是 0.0308 [0.0286, 0.0341]，稳定达标。
   - **通过的 M1 不是"椭球类"。**
     - M1 的 g 在 u1 ≈ 0 两侧近似对称（V 形），边缘是 |u1| = 常数这两片曲面。
     - 严格的单二次曲面阈值 S1（g 单调）只有 0.1199 [0.1086, 0.1295]，比 M1 差 0.080 [0.070, 0.090]。它比 Gate 3 的 triple（0.138）好 0.018 [0.009, 0.033]，但相对于 0.04 这个门槛，仍和 |a3|、triple 在同一量级。
     - 所以"单个椭球阈值"不够，单个二次量的绝对值够。
   - **M1 的那个二次量可以读出物理意义（第 4 节）。**
     - u1 ≈ a3 + 54.7 a4a8 + 11.3 a4a7 + 10.9 a5a6 + 8.8 a5a8 + …（按 a3 的线性系数归一）。
     - 其中 a4a7、a4a8、a5a6 正是 MFE 方程 da3/dt 里的三个二次项，但权重比例与方程中的瞬时系数不同。
     - 可以读作"a3 加上会驱动 a3 的 y–y 乘积"，即流向涡幅值加上它的非线性强迫，边缘大致在它的绝对值达到某个值时。这是对拟合结果的读法，没有单独检验。
2. **阶梯（图 2）：** M1 0.0394，M2 0.0308，M3 0.0191，M4 0.0177。
   - 每一级都比上一级好，CI 都不含 0。
   - M3 与 Gate 3 的 MLP 上限（0.0199）无差别：−0.0008 [−0.0025, +0.0013]。
   - M4 的中位数比上限略好：−0.0022 [−0.0042, −0.0009]；尾部略差：q90 0.116 对 0.094，差值 +0.021 [−0.000, +0.042]。
   - 也就是说，4 个二次型的函数已经追平了 9 维 MLP。
3. **物理指定的 k = 2（u1 = a3²，u2 = |y|²）不够。**
   - g 自由时 0.1254 [0.1126, 0.1368]，相加版本 0.128（α3 = 3.26e-3，αy = 2.16e-2），两者没有差别。
   - phys2 比 |a3| 只好 0.014，相加版本好 0.011，主要好在尾部（phys2 的 q90 从 1.02 降到 0.62），离 0.04 很远。
   - 学出来的 M2 比它好 0.095。缺的是 a3 的符号信息，以及 y 分量之间的乘积（交叉项），而不是 |y|² 这个能量。
4. **k = 2 的形状（图 3a）：**
   - 学出来的 M2 在 (u1, u2) 平面上的临界线由两条近似竖直的线（u1 = ±常数）和顶上一条横线（u2 = 常数）组成。B 区是 |u1| 大于阈值或 u2 大于阈值（c* 方向 +1，拱外 g ≥ c*）。
   - 这是"取较大者"型的组合，不是相加。按你给的读法，属于"少数机制，但组合规律不是简单相加"。
5. **噪声族 ε > 0（图 5）：所有冻结模型都系统性偏早，误差随 ε 变小而变大。**
   - M1–M4、S1、phys2，以及 Gate 3 的 |a3|、triple 和 MLP 上限，中位数都约为：ε = 1e-2 时 0.09–0.13，1e-4 时 0.29–0.33，1e-6 时 0.48–0.52，几乎全是负号（预测的 s_c 太小）。
   - 只有 gain (i)（σ = 0）不随 ε 变：三档都约 +0.15。
   - 随机射线的 y 能量占比 99% 在 0.10 以上（最小 0.021），没有"y 种子极小"的样本，所以二次型学不到 s_c 对 ln ε 的依赖。
   - 90° 方向上 M1 正常（0.26），M2–M4 差（1.0–1.2）。
6. **第 1 项（图 1，纯描述）：** 点没有塌成一条曲线。
   - (|a3|, |y|) 平面最有结构：|y| ≲ 5e-3 时边缘几乎全在 |a3| ≈ 3e-3 这条竖线上（边缘处 |a3| 的中位数 3.05e-3）；|y| 更大时，下包络向小 |a3| 弯；包络上方散得很开。
   - 散布与 1−a1、a9 无关：带符号相关约 0.01，方向占比的相关 ≤ 0.02；它跟 a3 的占比和整体幅值 s_c 走。
7. **第 3 项（图 6）：gain (i) 在随机射线上失败，主要不是因为 y 的能量占比，而是因为 a3 占比。**
   - 误差对 y 能量占比只有弱依赖：零拟合下 |ln| 中位数从 0.17 升到 0.47。
   - 按 a3 占比分箱，规律清楚得多（图 6d、6e）：a3 占比 ~1e-4 的射线零拟合偏晚 +1.75，占比 ~0.47 的偏早 −0.17。
   - Gate 3 图 3 (b1) 左边的峰（c < −4.5）是 680 条（6.8%）几乎不含 a3 的射线：99.7% 的 a3 能量占比 < 0.01，66% < 0.001；a4、a8 占比偏高。
   - 这个峰**不是数值下限造成的堆积**：c 与 σ 无关（差 ~1e-8），98% 的射线最大值出现在 t > 0，没有重复值，tr P 远离下溢。它是物理上的一个子群：没有 a3 就没有 lift-up 瞬态，tr P 只增长约 15 倍。
   - 这些射线零拟合预测偏晚：中位数 +1.34，即晚约 3.8 倍。
8. **Gate 3 的 triple 含二次项：** 3 个线性项加 6 个二次项（3 个平方、3 个交叉），共 9 个系数加截距。其中 a3² 的系数最大（标准化后 779）。

**判据（config 里预设，原样执行）：** "记录 median ≤ 0.04 的最小 k" → **k = 1**（0.0394）。嵌套检查没有违反。

**需要和判据一起看的事实（不改判据）：**

1. **M1 是擦线。**
   - 点估计在 0.04 以下，但 CI [0.0363, 0.0427] 跨过 0.04。
   - 4 个随机重启都收敛到同一类解（val NLL 0.2714–0.2729），测试中位数分别是 0.0394（选中的那个，val NLL 最低）、0.0414、0.0416、0.0416。
   - 两个热启动（从凸二次 logistic 和从 a3² 出发）停在另一个局部解：val NLL 0.2724，测试约 0.101。
   - 如果用另一个随机重启，或者按 CI 上界判，结论会是 k = 2。
2. **"k = 1 等价于椭球类"只在 g 单调时成立。**
   - 你说 k = 1 等价于单个二次型阈值（椭球类）。但阶梯里的 M1 按设定没有单调约束，它学到的 g 是 V 形，等于用 |u1| 当坐标。
   - 严格的单二次曲面类 S1 是 0.120，失败；它比 triple 好 0.018，但离 0.04 还差 3 倍。
   - S1 学到的二次型也不是一个真正的椭球。它实际上是以 a3² 为主的退化（半正定）二次型：主轴几乎就是 a3²，边界处占二次部分的 85%；唯一的负本征值只有最大值的 0.13%，另有 3 个近零。几何上更像一个椭圆柱。

## 4. 二次型的结构（图 4；完整的本征值和模态组成在 results.json → structure）

Q_i 只能确定到 (u_1..u_k) 的可逆线性混合，所以下面按规范基报告（h7）。"消融重要性"指把某个规范坐标固定在中位数后，val NLL 增加多少。

- **S1：**
  - u1 几乎是纯二次型（线性项只占 0.6%）。
  - 主轴依次为 a3²（λ 相对值 1.00）、a8²（0.075）、a4²（0.026）、a6²（0.006）。
  - 它相当于一个以 a3² 为主、各 y 分量只做小修正的阈值。
- **M1（唯一的 u1）：**
  - 线性项 b 几乎全部在 a3 上（a3 占 1.00）。在边界状态上，线性部分占 |u1| 的 86%。
  - 二次部分是**交叉项**：本征值成对出现（+796/−780 对应 a4±a8，+160/−145 对应 a5±a6）。
  - 按 a3 的系数归一后：

    **u1 ≈ a3 + 54.7 a4a8 + 11.3 a4a7 + 10.9 a5a6 + 8.8 a5a8 − 1.7 a6a8 + …**

    a1、a2、a9 的线性系数都 ≤ 0.02。含 a2 的乘积项系数不超过 0.8（a2a3 0.80，a2a4 0.68），在边界幅值下贡献很小。
  - 边界状态上 u1 一半为正、一半为负（50%）。g 关于 0 近似对称：dc/du1 > 0 的比例为 0.50，与 c 的 Spearman 相关 0.02。所以边缘是 |u1| ≈ 常数。
  - **与方程的对照：** MFE 的 da3/dt 恰好只含 a4a7（系数 0.308）、a4a8（0.058）、a5a6（0.308）三个二次项。M1 用的正是这几项（另加 a5a8），但权重比例与瞬时系数差很多：a4a8 被放大约 950 倍，a4a7、a5a6 约 35 倍。
  - 我的读法是"a3 加上它在一段时间内会受到的 y–y 强迫"，这只是对拟合结果的解释。
- **M2：**
  - u1 与 M1 的 u1 几乎相同：b 全在 a3，线性占比 0.86，交叉项 a4a8、a5a6。消融重要性 9.67。
  - u2 是一个近似正定的"能量型"量：a3²（1.00）+ a8²（0.77）+ a4²/a5²（约 0.2）+ 0.5 份的 a3 线性项。消融重要性 0.16。
  - 两者组合成第 0 节第 4 条所说的"取较大者"型。
- **M3、M4：**
  - 用的还是同一组成分：a3（线性和平方）、y–y 交叉项（a4a8、a4a7、a5a6、a5a8），以及 a8²、a4²、a5²。
  - 各形式之间混合更多，单独一个形式不再有干净的读法。
  - M4 的 u2 里第一次出现 a2 的线性项（a2 0.70），但它在边界处只占该形式的 6%。
  - a1 和 a9 在任何一级的主要成分里都没有出现。
- **phys2：**
  - 直接对原始坐标做消融（把一个量固定在中位数，在 val 状态上看 val NLL 的增加）：a3² 为 0.257，|y|² 为 0.130。这是报告时另算的，不在 results.json 里。
  - 规范基给出的顺序正好相反：第 1 个规范坐标约 99% 是 |y|²，J 份额 0.98；第 2 个约 99% 是 a3²，J 份额 0.02。results.json 里的消融 1.23 / 0.06 对应的是这两个规范坐标。
  - 这说明审查时指出的问题确实存在：J 会被少数 |u| 很小的状态主导。所以判断哪个量为主，以原始坐标的消融为准，即 a3² 为主、|y|² 为辅。

## 5. k = 2 平面（图 3）

- **(a) 学出来的 M2：**
  - 测试射线的边界状态在 (asinh(u1/τ1), asinh(u2/τ2)) 平面上，大部分落在两条近似竖直的带上，位置是 asinh(u1/τ1) ≈ ±3.7–3.8，即 |u1| ≈ 常数。

  - 但边界状态在这条 L 的右上方散得很开（q90 0.62）：这两个量不够。

**(b) Gate 3 图 3 (b1) 左边的峰（c ≈ −6）：**
- **是哪些射线：**
  - 边缘处 c < −4.5 的射线共 680 条（6.8%）。切点取 −5 和 −4 时分别为 527 条和 793 条，下面的结论都不变。
  - 99.7% 的 a3 能量占比 < 0.01，66% < 0.001：中位数 5.0e-4，全部射线是 0.059。
  - 反过来不成立：a3 占比 < 0.01 的 2251 条射线中，只有 30% 在峰里。按 a3 占比细分，在峰里的比例是：< 1e-3 时 63%，1e-3–3e-3 时 31%，3e-3–1e-2 时 6%。
  - 不在峰里的那些低 a3 射线，增长仍大得多（c − ln|y0|² 的中位数 10.8，t_max 中位数 378）。所以"几乎不含 a3"要理解为 a3 占比 ≲ 1e-3。
  - 方向能量的平均组成：a3 0.001（全部射线 0.109），a4 0.179（0.112），a8 0.144（0.111），其余各约 0.11。
  - 它们的 s_c 偏大：中位数 0.020，全部是 0.0126。
- **是否是数值下限造成的堆积：不是。** 逐项核查：
  1. c 与 σ 无关：σ = 3e-7 和 σ = 0 的 c 之差，中位数 1.7e-8。所以不是噪声项 σ² tr Q 的下限。
  2. 最大值不在 t = 0：98.4% 的射线 t_max > 0，中位数 t = 14.75。只有 1.6% 的 c 恰好等于 ln|y0|²。
  3. c − ln|y0|² 的中位数是 2.69（tr P 增长约 15 倍），5%–95% 分位为 0.65–3.93，没有贴在某个下界上。
  4. 没有重复值：按 1e-6 取整后，最大重数为 1。最小 tr P = 7.3e-4，远离浮点下溢。
  5. 没有边缘低于网格。
- **它是什么：**
  - 一个物理子群：a3 占比 ≲ 1e-3 的射线大多没有 lift-up 引起的 u 瞬态，y 扰动只增长约 15 倍（t ≈ 15 时达到最大）。
  - 它们靠 y 自身的幅值越过边缘，所以边缘处的 c 约为 ln(|y0|²·15)。其中位数 −5.6，其余射线是 +12.9，差约 18 个 e 倍；按增长量 c − ln|y0|² 算，中位数 2.7 对 23.6。
  - 零拟合在这些射线上：中位数 +1.34（晚约 3.8 倍），5.6% 不越过阈值。重新拟合后，测试射线里属于这个峰的 88 条中位数 +1.66，其余 1360 条为 0.134。

**(c) Gate 3 的 triple 是否含二次项：含。**
- config 里是 `degree: 2`。代码用 `poly_features(·, 2)`，对 (1−a1, a2, a3) 取全部线性项和全部二次单项式，即 combinations_with_replacement。

- 标准化系数里 a3² 最大（779），其次是 a2a3（−28）、a2²（6.2）、(1−a1)a3（−4.9）。

## 9. 跑全量之前的修改（1% 测试与独立代码审查；都没有用到测试数据）

1. **1% 测试 v1：** 发现 M2 的随机重启比它自己的特例 phys2 差得多（val NLL 0.36–0.46，phys2 是 0.25），属于优化失败。于是加了 h4b 的物理热启动。
2. **1% 测试 v2：** 发现 phys2 的精确复制在 Adam 的第一步就被破坏（val NLL 从 0.25 变成 12.6）。原因是缩放单位下复制来的二次型系数约 1e-3，比步长 3e-3 还小。修正为：
   - 写入的二次型归一到单位范数，τ 同步缩放，函数不变；
   - 每次训练的起点本身也作为"最佳状态"的候选。
3. **独立代码审查**（3 个方向的审查者，各配一个对抗式验证者）确认的问题和处理：
   - 上面两处，已修，验证者复核过。
   - 原定的"严格 k = 1"（凸二次 logistic）受 ridge 罚项和特征标准化方式限制。验证者在全量数据上核查后认为这在全量时不是问题。我仍然换成了 S1，与 M_k 用同一套参数化和训练方式，凸 logistic 降为诊断。
   - 结构报告漏了线性项 b（在 1% 测试里它占 u 的大部分），已补上。
   - 规范基的定向原来几乎是随机的，J 的份额会被少数状态主导，已改，并加了消融重要性。
   - 在判据旁加了嵌套检查。
   - 噪声族部分在 config 里写明是描述性的。
   - 被验证者否定的发现：噪声族应给 CI、阶梯一定会被优化拖累、结构输出与请求不符。这些都没有改代码；但其中两条的建议已经在上面两处修正里体现。
4. **学习率线性预热 200 个 epoch：** 验证者看到，归一化后的热启动在全量数据上大约 20 步内仍会被推离起点。
5. **1% 测试 v3、v4：** 确认修改后流程正常：M2 的热启动不会比 phys2 差，嵌套成立。
6. 判据、门槛和选模型规则（val NLL 最低）从头到尾都没有改。
7. **报告的独立核对（跑完之后）：** 两个检查程序把报告里的数字和论断对照原始输出重算了一遍。发现的问题都已改正：
